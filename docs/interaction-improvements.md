# 交互体验优化清单

日期：2026-09-29。

本文记录对 Web、桌面端和移动端主流程做交互审查后确认的待优化事项，按批次推进。每批完成后直接删除对应条目；全部完成后删除本文。

## 第一批：功能缺陷与数据丢失

- 助理列表「发消息」跳到 `/inbox?scope=internal&target=`，`/inbox` 不读取 `target`，落到客服收件箱。改为与其他联系人一致的 `/chats?target=`。
- 输入框在发送期间 `disabled`：桌面端连续输入会丢字，移动端每发一条键盘收起。发送期间保持可输入，只用提交状态防止重复提交；移动端发送按钮按下时不抢焦点。
- 新建页 `FormActions` 的 `cancelTo` 链接在保存中仍可点，离开后请求继续完成，记录被静默创建。保存中与 `onCancel` 分支一样停用。
- Web 端启动检测失败只打日志，页面一直转圈。失败时显示错误与「重试」。
- 身份、工作区列表、邀请等读取失败页只有一行文字，文案统一为“无法读取登录状态”且与实际失败对象不符。统一为带「重试」的错误状态，文案按读取对象区分。
- 邀请成员弹窗在角色读取失败时一直转圈。显示读取失败与重试。
- Android 返回键在一级页签上执行 WebView `goBack`，会退回工作区列表或上一个工作区。一级页签不在收件箱时先切回收件箱，已在收件箱时退到后台。

## 第二批：收发体验

- 切换会话时整个会话区按 `key` 重建，未发送的正文、提醒对象和引用丢失。按会话和对客/备注模式保存草稿，会话列表显示草稿标记。
- 发送失败同时弹 Toast、回填输入框并留下失败气泡；气泡「重试」只把内容回填输入框并覆盖当前输入，编辑后重发会留下删不掉的旧失败项。失败只保留气泡，「重试」原样重发，另提供「删除」。
- 打开有未读的会话直接贴底并把最后一条记为已读，没有未读分隔。首次打开定位到第一条未读并显示“以下为新消息”，已读按实际看到的范围推进。
- 点击会话后列表高亮取自会话摘要加载结果，主区先整块显示加载中，时间线再加载一次。高亮直接用路由中的会话编号，会话头先用列表行数据渲染，只在时间线区域显示加载。
- 历史消息靠「加载更早/更晚消息」按钮，失败时 Toast 与原地错误重复。接近顶部或底部时自动加载并保持阅读位置，失败只在原地显示重试。
- 输入框不支持粘贴图片和拖入文件；Esc 不能取消引用；提醒候选不支持 Tab 选中；自己的消息悬停不显示回复按钮。

## 第三批：会话状态与导航

- 归档、置顶、免打扰、标为未读没有成功反馈，归档后会话直接消失，找回入口只在「设置 → 已归档的聊天」。归档后提示“已归档”并提供撤销；置顶、免打扰先更新界面，失败回滚。移动端已归档页按行记录保存状态。
- 会话个人操作入口不一致：桌面端会话头只有归档，置顶、免打扰、标为未读只在右键菜单，列表行没有悬停「⋯」；移动端单聊与 AI 聊天的「⋯」菜单缺少置顶与免打扰，群详情缺少置顶。各端补齐同一套操作。
- 未登录或会话过期时打开深链接，登录后固定进入收件箱；过期时静默跳到登录页。跳转登录前暂存当前工作区地址（参照 `pending-invitation`），登录后恢复，并提示“登录已过期”。
- 切换工作区时清空全部查询缓存（含账号级工作区列表），整屏多次加载，且固定进入收件箱。保留账号级缓存，加载时先显示外壳，按工作区在本机记住最近路径。
- 桌面端启动时服务器暂时不可用会返回连接状态，显示首次连接页。区分“未配置服务器”和“暂时连不上”，后者显示“无法连接到 <地址>”与重试，并在恢复联网时自动重试。
- 连接到尚未完成首次安装的服务器时提示“检查地址”。改为说明需先在浏览器中打开该地址完成安装。
- 托管部署下 Web 端仍显示「在客户端中使用」，客户端连接后只能停在不支持登录的页面。托管部署隐藏该入口；未安装客户端时弹窗提供下载入口。
- 工作区不可访问或路径不存在时静默改道到工作区列表或收件箱。改道时提示原因。
- 从助理编辑页、渠道新建页返回会丢失列表筛选；“返回来源列表”有 `returnTo` 白名单、透传 `location.search`、手工拼接查询三套写法。抽成共用 hook，覆盖返回、取消、保存后跳转和记录不存在时返回。
- 移动端客户会话的「接管」「重新打开」只在「⋯」菜单，输入区只显示不能回复的原因。在原因条右侧直接提供对应操作。
- 移动端真人单聊从草稿发出首条消息后整页替换并收起键盘。与 AI 聊天一样，草稿与正式会话共用同一页面实例。
- 冷启动经过多层加载占位，部分写死英文 `Loading`，可见的“加载中”时有时无。统一全屏加载组件，文案走国际化，短加载不显示文字。

## 第四批：一致性与打磨

- 新建成功后去向不一致：知识库新建后应进入内容页；渠道新建补成功提示。
- 自动保存的编辑页没有保存状态，校验不通过时离开不提示。统一显示保存状态，校验失败时登记为未保存。
- 新建团队、新建联系人、字典项编辑等弹窗按 Esc 或点遮罩直接丢弃已填内容。有改动时先确认放弃修改。
- 知识库设置只能从列表菜单进入。内容页页头加「设置」，从内容页进入的设置页返回内容页。
- 邀请成员完成后列表仍停在「在职」筛选，看不到新邀请。完成后切到已邀请筛选。
- 团队详情页不能改名和删除；成员行点击同事进聊天、点 AI 员工进编辑页；行首常驻勾选框。补齐页头操作，统一行点击结果，勾选框改为进入选择模式后显示。
- 违反管理界面约定：`SwitchCardField` 与角色成员区块使用带边框卡片；登录、首次安装、注册、创建工作区表单把提交按钮放进 `FieldGroup`；全局搜索框使用 placeholder；知识库「召回测试」是纯图标按钮；「把助理换到这台电脑」确认按钮为红色；文档删除确认标题不带对象名；Telegram 连接表单操作区间距与按钮位置和其他表单不一致。
- 全局搜索中消息与人员分组的「查看全部」未接入，显示为停用；进入分页视图后没有返回入口，方向键到达不了「查看全部」。
- 未上线功能不露出：输入框中常驻停用的语音按钮、设置导航中 Webhooks 与开放 API 的“即将推出”占位项。
- 有负责人时「接管」客服会话不需确认。确认弹窗写明从谁手中接管。
- 群资料「更多」按钮缺少 `title`/Tooltip；「解散群聊」挂在群头像字段旁；「退出群聊」只在成员列表自己那一行的菜单里。危险操作集中到群资料底部。
- 首次安装与创建工作区暴露“工作区标识”和 `#/w/<slug>` 地址。标识自动生成，工作区列表副标题换成成员数等有用信息。
- 键盘与快捷键：宽度拖动手柄不支持方向键和双击复位，拖动中每次移动都写本机存储；桌面端前进后退没有快捷键；搜索快捷键文案不按平台显示，搜索打开时再按 ⌘K 不关闭。
- 移动端：iOS 不能从左边缘右滑返回（在前端实现，与 `app:back` 走同一路径）；非群主的群资料行仍显示可编辑箭头；发送与工具按钮等触控区域小于 44px；再次点击当前页签不回到顶部；列表没有下拉刷新；创建群聊页嵌套滚动且「完成」在底部；加载失败和空状态未统一使用 `MobilePageState`，类型筛选控件不统一。
- 移动端软键盘与安全区（Android 15 全面屏的 IME 与系统栏 inset、iOS 键盘弹出时底部安全区留白）需在真机确认后处理。
