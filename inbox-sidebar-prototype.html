消息页中栏（会话列表）交互原型

左侧为可交互原型：可点击范围纵栏、收纳按钮、加号菜单、会话项，聚焦搜索框进入搜索模式（快捷键 Ctrl/⌘ K），Esc 退出。右上角按钮可切换原型界面语言，用于中英文案对照；设计说明保持中文。

1定位与原则

中栏是全部消息来源的统一收件箱：客服会话、内部单聊群聊、第三方账号会话、外部协作和联邦会话都进入同一时间线列表，与 chat-roadmap「统一 Conversation 容器」的模型一致，不为来源分裂成多个列表页。

  • 「全部」= 与我相关，不是企业全量时间线：包含我参与的内部会话、我绑定账号的第三方会话、我负责或负责过的客户会话。排队和 AI 接待中的客户会话属于共享队列，只在「客户」范围可见——对应 roadmap 10.8 用户 Mailbox 与客服共享收件箱分离的模型。因此即使 AI 同时接待上千条会话，也不会淹没任何人的「全部」列表；AI 转人工升级时会话进入「排队」，通过队列计数与范围圆点提醒。
  • 默认零噪音：「全部」只按 last_message_at 倒序展示，来源差异只通过头像角标和极简标签表达，不引入分组标题。
  • 来源用筛选表达，不用导航表达：范围筛选是同一列表的过滤器，切换不改变路由结构，仅同步 URL 查询参数以便恢复。
  • 能力渐进：范围筛选项只在对应能力启用后出现（见第 8 节阶段映射），首期界面只有搜索、加号和列表本身。

2布局与尺寸

  • 中栏总宽 344px = 48px 范围纵栏 + 296px 列表（PageSplit 增加消息页专用档位）；纵栏收起或未启用（首期只有「全部」）时为 296px。列表列比通用二级栏略窄，双行列表项在 296px 下仍有充足截断余量。窄视口 paneOnNarrow="fill" 占满，选中会话后以 Sheet 打开主区（维持现状）。
  • 顶部操作行高 56px（h-14），与右侧会话页头同高并共享 border-b，形成贯通的水平线。
  • 消息页中栏不显示模块标题（遵守「二级栏显示模块标题（消息页除外）」的约定），搜索框即是这一栏的头部。
  • 列表项 rounded-xl px-3、头像 36px、hover/选中用 accent 浅蓝，全部沿用现有 InboxPage 样式。
  • 视觉减负：搜索框用浅灰填充无边框（聚焦才出描边）、收纳与加号为 ghost 图标按钮、纵栏不带独立底色，仅以一条比中栏边框浅一档的竖分隔线界定列表左缘。字号收敛为名称 13 / 预览 12 / 时间等辅助 11 三档（微标签 10.5，纵栏标签 10 并带截断保护）。

3顶部：收纳 + 搜索 + 加号

收纳按钮（最左，ghost 图标）：收起/展开范围纵栏，位置固定不随纵栏消失，展开与收起互为可逆。收起后中栏回到 296px；此时若当前范围之外存在个人未读或排队队列有等待，按钮右上角显示圆点，保证收起不等于失联。纵栏未启用时该按钮不渲染。

搜索框（中，弹性宽度）：

  • 浅灰填充、无边框，聚焦才出现描边；Ctrl/⌘+K 或 / 聚焦，快捷键提示放 tooltip 不占输入框。
  • 聚焦即进入搜索模式（见第 7 节），失焦不自动退出，由 Esc 或清除按钮退出，避免点击结果时列表闪回。

加号（右，ghost 图标）：点击弹出「发起会话」菜单，服务于用户主动发起的会话——客户会话由渠道入站产生、第三方账号会话由绑定账号投影产生，都不在此新建：

  • 发起单聊：打开人员选择器，可选企业成员与 AI 员工（同一 ChatSubject 路径）；同一主体对收敛到既有长期单聊，已存在时直接打开。
  • 创建群聊：打开建群对话框（群名 + 多选成员，成员含 AI 员工）。
  • 邀请外部协作：阶段 4 能力，未启用前不渲染；原型中以「即将推出」灰显仅作演示。

菜单项保持两三个高频动作；不把「绑定外部账号」「新建渠道」等配置入口放进来，它们属于集成/设置页。

4范围筛选

范围切换使用中栏左缘的 48px 范围纵栏（图标 + 双字标签），Telegram 文件夹栏验证过的模式。此前评估过的三种方案都有硬伤：横向 chips 数量一多就要滚动、被滚出视口的范围不可发现；下拉浮层遮挡列表且选一次收一次；内嵌展开面板会把列表上下推挤。纵栏同时满足四个约束——全部范围常驻可见、单击直达可连续切换、零遮挡、零布局位移，数量增长只消耗纵向空间。纵栏不带独立底色，只用一条浅一档的竖分隔线界定列表左缘——既给列表一个稳定的起始边，又不会重到读成第三条独立面板。

范围统一按「我在和谁说话」一个维度命名：全部 / 客户 / 内部 / 伙伴，之后是绑定账号项：

  • 客户：对外接待会话，对齐 roadmap「客户会话」术语。
  • 伙伴：受管外部协作与联邦会话合并——对方走访客门户还是部署了 Cervi 是实现差异，不是用户心智差异；列表项上以琥珀「外部」标（访客）和紫色企业名标（联邦）区分，将来有真实需求再加子筛选。
  • 绑定账号直接上纵栏：不设统一「外部账号」分类，每个绑定账号（如 TG·销售号）以平台图标 + 账号备注名作为独立纵栏项，与「账号视图隔离」的模型同构，也免去账号子筛选行；账号连接异常在对应项上标注。
  • 徽标降噪：各范围只用小圆点表示存在个人未读（静音不计、客户共享队列不计，具体数字在列表项上）；唯一的数字徽标是「客户」的琥珀色排队数——这是需要行动的队列信号，跨范围可见。
  • 「仅未读」开关固定在纵栏底部，与范围正交、跨范围保持，激活时空列表提示「没有未读会话」。
  • 渐进显示：只有「全部」一个范围时不渲染纵栏和收纳按钮，中栏保持 296px。

客户范围额外出现队列子筛选：排队 n / 我负责 / AI 接待 / 同事 / 已关闭——按「这条会话现在归谁」做互斥且穷尽的划分，与 ServiceSession 的「批次状态 + 负责人」严格同构（排队 = 未分配的等待批次；我负责 / AI / 同事 = 未结束批次的负责人；已关闭 = 最新批次已结束）。分段控件只平铺高频三段（排队 / 我负责 / AI 接待），低频的「同事」「已关闭」收进行尾的「更多」下拉——它们是巡查与回溯入口，不是日常工作台；选中后「更多」位置显示所选项名并保持选中态，保证状态可见。这也让分段在 296px 列表宽下（含英文文案）不换行：

  • 默认落点是「我负责」：客服进来第一眼是自己的工作台；排队压力由琥珀数字（分段与纵栏徽标）常驻提醒，需要领取时一步可达。
  • 「排队」按等待时长升序、时间列显示「已等待 x 分钟」（琥珀色）；点击排队会话进入领取动线（主区顶部出现「领取」，领取命令属于后续 PR）。
  • 「AI 接待」列出 Agent 正在自动处理的会话，供巡查与随时人工接管；不产生个人未读，也不进入「全部」。AI 升级转人工时流转到「排队」并计入队列数字。
  • 「同事」列出其他成员负责中的会话，列表项标注负责人；首期按企业边界全员可见，引入团队权限后再收敛可见范围，界面结构不变。不产生任何提醒。
  • 「已关闭」是归档检索视图，按最后消息时间倒序、懒加载分页；客户在已关闭会话上再次发消息时，同一 Conversation 开新批次并自动流回「排队」，无需手动重开。
  • 信号语义：只有「我负责」的新消息计入个人未读（纵栏圆点的来源）；「排队」用琥珀数字；AI 接待、同事、已关闭不产生提醒。
  • 不设「全部」子项：五段划分已穷尽，跨状态找历史会话由搜索承接（搜索继承客户范围）。

子筛选只用于「状态与责任」维度，不用于会话形态：内部、伙伴和账号范围是个人收件箱，没有队列语义，不设「单聊/群聊」这类形态子筛选——列表、角标和搜索已经足够。将来某范围出现真实的状态维度（如伙伴按企业筛选）再按同一模式补充。

5列表项解构

元素规则
头像 + 角标36px 圆形首字头像。右下 16px 来源角标表达平台/来源：网站（蓝·地球）、微信（绿）、Telegram（青·纸飞机）、联邦（紫·建筑）、外部协作（琥珀·人）、AI 员工（灰·机器人）。内部会话不加角标，保证最高频场景最干净；单聊在线状态沿用右下绿点（与角标互斥，取角标优先）。
第一行名称（截断）＋条件标签＋静音图标＋右侧时间。标签只有两种：群聊含外部参与者时的持续「外部」标（琥珀描边，对应路线图第 11 章要求）；联邦会话显示对方企业名（紫描边）。
第二行预览（截断）＋右侧未读徽章。群聊预览带发送者前缀「李雷：」；草稿显示红色「[草稿]」并保持原时间排序；被 @ 显示蓝色「[@我]」前缀；同事负责的客户会话显示负责人小标。
账号标识第三方账号会话在预览前显示灰底小标「TG·销售号」，明确收发账号（角标只表达平台，账号标才是发送路由身份）。同一自然人多账号绝不合并。
未读徽章常规为品牌蓝圆徽；静音会话降级为灰徽，且不计入范围圆点和一级轨角标。99+ 封顶。
置顶置顶会话排最前，第二行行尾显示图钉小图标，不设分组标题。置顶/静音/归档是个人视图状态（conversation_user_states），通过列表项右键或长按菜单操作。

6排序规则

  1. 置顶组按 last_message_at 倒序在最前。
  2. 其余按 last_message_at 倒序；预览跳过已删除消息（沿用路线图 5.3 的水位语义）。
  3. 例外一：客户范围的「排队」按等待时长升序（最久未接待在最上），这是队列公平性要求。
  4. 例外二：「已关闭」按最后消息时间倒序懒加载，是归档检索视图。

7搜索模式

聚焦搜索框后，筛选行和列表被搜索态整体替换（同栏内切换，不弹独立浮层）：

  • 范围继承：第一行显示范围 chips——当前范围（如「客户」「TG·销售号」）+「全部消息」。进入时默认选中当前浏览范围，一次点击即切全局，实现「既可全局也可限定范围」。当前范围为「全部」时只显示「全部消息」。
  • 类型过滤：分隔线后是类型 chips「会话 / 消息 / 联系人」，默认全选中（分组展示），点击可只看某一类。
  • 空查询：显示「最近打开」列表，兼作快速切换器（⌘K 的主要用途）。
  • 结果分组：会话（按名称匹配）、消息（全文匹配，显示所在会话 + 高亮片段 + 时间，点击跳到消息上下文）、联系人与成员（可直接发起会话）。每组最多 5 条 + 「查看全部」。
  • 键盘：↑↓ 跨组移动，Enter 打开，Esc 退出并还原浏览态；底部固定快捷键提示条。
  • 会话内搜索不在此处，放在会话主区页头（范围天然是当前会话），两个入口不混用。
